# Bayan wake-word trainer (Colab)

Public host for the Colab training notebook only. Open it directly in Colab:

https://colab.research.google.com/github/AhmedElbedeawy/bayan-wake-train/blob/main/bayan_wake_train_colab.ipynb

The notebook trains a local ONNX "Bayan" wake-word detector (openWakeWord-style) from a
`wake_data_<version>.zip` produced by the recorder tool. It contains training code only — no
application code, no credentials.
